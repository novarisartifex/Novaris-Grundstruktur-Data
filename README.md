# Novaris Grundstruktur – Data

The canonical source is `Novaris_Grundstruktur_v1_3_Standalone.html` in the Novaris Google Drive folder. It contains 24 embedded images and four tabs: Personen, Bereiche & Gebiete, Szenen, Weltstruktur.

This repository is intentionally **not published** yet. `manifest.json` has `status: pending_assets` and `latest: null`; clients must not install updates from this manifest. A release must include the complete source (including image assets), exact SHA-256, byte count, a monotonically increasing version, and a successful content validation before setting `status: published`.
